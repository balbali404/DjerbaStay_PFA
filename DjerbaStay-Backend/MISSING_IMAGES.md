## How to Install Missing Images

1. Download images from Booking.com or similar for each hotel
2. Save them to `DjerbaStay-Frontend/public/images/accommodations/`
3. Use the exact filename from the table above (e.g., `hyatt-stones.png`)
4. Run `npm run prisma:seed` to update the database

## Alternative: Use Fallback Images

If you don't have images for all hotels, you can update the seed to use fallback images for missing ones by mapping more hotels to existing images:

```javascript
const imageFileNameMap: Record<string, string> = {
  // Add more hotels here pointing to existing images
  "48477488": "four-seasons-djerba.jpg", // Hyatt Stones → use fallback
};
```
